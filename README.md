# Garde-manger

Appli Android pour scanner ses produits avant de les ranger, savoir dans quel
frigo ou placard ils se trouvent, et recevoir un rappel avant qu'ils expirent.

## Récupérer l'APK
À chaque modification, GitHub fabrique l'APK tout seul (onglet **Actions**,
5 à 10 minutes). Il apparaît ensuite dans **Releases** → `garde-manger.apk`.
Ouvre cette page depuis ton téléphone, télécharge le fichier et ouvre-le.

## Modifier l'appli
Tout le code est dans `www/index.html`.
